Поля заполняй строго в этом порядке: сначала найди место в тексте и выпиши его, потом — значение
из этой цитаты. Значение, которого нет в цитате, не пиши:
- key — код поля;
- chunk_id — номер фрагмента в квадратных скобках (например, "F3"); null, если значения нет;
- quote — дословная цитата 5–60 слов, где указано значение; null, если значения нет;
- raw — как значение написано в цитате (например, «15 (пятнадцати) рабочих дней»);
- value — значение из цитаты; null, если в документе оно не указано явно. Не вычисляй и не
  додумывай: «не позднее 30 числа месяца» — это не число дней, value null;
- unit — для сроков "working" (рабочие дни) или "calendar" (календарные дни); для количества —
  единица измерения, как в документе; иначе null.
